# ISO 20022 schemas for the versions LHV publishes no XSD for

2026-10-24. Decision 550.

- LHV's `partners.lhv.ee/assets/files/XSD/` (and the docs mirror) has camt.053.001.08 and
  camt.052.001.08, but not camt.053.001.02 / camt.052.001.06, the answers to camt.060.001.03.
- iso20022.org: every HTML page (`/`, `/message-archive`, `/iso-20022-message-definitions`)
  answers 403 "SWIFT site off-line" to curl, with or without a browser User-Agent. The schema
  files themselves are served directly (200, no UA needed):
  `https://www.iso20022.org/sites/default/files/documents/messages/camt/schemas/<id>.xsd`.
- Downloaded and pinned (sha256):
  - camt.053.001.02.xsd, 66 010 B, "SWIFTStandards Workstation R6.1.0.2, 2009 Jan 08",
    `d664afd198d1f36386a14e2bfd0505c80c1291a5357d8132aa6ab5443a6f2f3d`
  - camt.052.001.06.xsd, 99 406 B, "Standards Editor R1.6.5.6, 2016 Feb 12, ISO 20022 version 2013",
    `0b33ce30c01ed3923a713a9610dc9b1fd0e17dde2121f61c3db737c3f5ce4504`
- Plain schemas, no imports; xmllint-wasm validates them like the bank's own. The published
  PAYMENT_VIBAN_SEPA/ACCOUNT_STATEMENT_CAMT.053A.xml sample has exactly one schema error
  against the 02 schema: its placeholder counterparty BIC `BICXXX` fails the BIC pattern.
- xmllint-wasm's default memory (32 MiB) is not enough for a 10 000-entry statement page;
  1 GiB (`maxMemoryPages: memoryPages.GiB`) validates the 10.6 MB mock.
